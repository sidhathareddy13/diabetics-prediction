What is Diabetes Risk Predictor?

Diabetes Risk Predictor is an educational health screening tool designed to estimate relative risk using a trained machine learning model built from a historical diabetes dataset.

How it works

The app collects five essential health inputs: glucose, blood pressure, BMI, age, and insulin. These values are processed through the existing trained pipeline and used to estimate a risk percentage.

Machine Learning explanation

The model used in this application is the active saved XGBoost pipeline at models/balanced_best_diabetes_pipeline.pkl. It applies median imputation and returns a probability estimate from five input features.

The binary model classification threshold is selected during training by maximizing balanced accuracy on out-of-fold predictions. Separately, the application display bands are 0–39% Low, 40–69% Moderate, and 70–100% High.

Input features

  • Glucose
  • Blood Pressure
  • BMI
  • Age
  • Insulin

Risk score explanation

Application display categories are:

  • 0–39% = Low Risk
  • 40–69% = Moderate Risk
  • 70–100% = High Risk

These categories are not medically validated diagnostic thresholds.

Privacy

User records, predictions, reminders, and health inputs are kept isolated per account. Each query uses the active authenticated user ID.

Educational purpose

This tool is for educational and risk-screening purposes only.

Medical disclaimer

This tool is for educational and risk-screening purposes only. It does not replace professional medical diagnosis, treatment, or advice.
